# 可独立复制的剪辑提示词

下面整段可发给具备视频编辑能力的助手；它不依赖本 Skill 的文件链接。实际软件是否具备抠像、转写和导出能力，仍须在执行时检查。

```text
请把我提供的真人口播视频和对应素材，剪成“贴纸讲解”风格。默认 16:9、1920×1080，保留本人原声。先区分参考片与待剪片，先理解完整口播，再按语义安排画面。不要照搬参考片的英文内容，也不要把所有视频套成四点或总分总。

画面基础：人物抠像，沿人物实际轮廓加明显而干净的白色外描边，放在浅米白、淡紫或淡粉的低对比网格背景上。居中时头顶和左右都有空间，肩部可自然出画；人物不得变形、顶头或贴边。人物移左时与左边留距离，右边展示信息。默认用关键词贴纸，不逐句堆满文字；需要完整字幕时另设字幕层并留出底部空间。

根据内容选择下列画面，可以自由组合和省略：
1. 普通铺垫、过渡、没有新重点的讲述：人物居中，保持干净，不强行出字。
2. 明确说“不是 A，而是 B”：左边放 A，配划线或否定符号；右边放 B，稍大、更肯定。分别在讲到各自概念时出现，先讲右边就先出右边。并列关系不要画成对错。
3. 宣布重要主题：短主标题出现在头顶上方，可从人物后方出现，停稳后必须完整可读。其他词按讲话顺序陆续加入，不能同时把答案摆满。
4. 明确列举若干观点：人物移左，右侧先出现概括标题，再随口播依次出现 01、02、03……；已讲过的项可保留，未讲到的先隐藏，实际有几项就显示几项。
5. 展开某个观点：左边大编号，右边短标题；引入后收成左上角“编号＋短名”的小标签，在该点讲解期间保留，下一点替换。没有分点结构就不强加编号。
6. 解释术语或强调数字：在人物周围放少量短贴纸，一个时刻只有一个主要新焦点。文字是准确摘要，保留否定、条件和单位，讲完就退场。
7. 讲案例、截图、录屏、图片或视频：人物移左，右侧显示对应素材；讲到运动时播放相关片段，不能用静帧假装演示。保持重要细节可读，必要时短暂放大素材。
8. 重大概念、关系或结论：可以换蓝色或柔和彩色背景，并用箭头、加号或等号解释关系。背景变化要有语义理由，不每句话换色。
9. 原口播有总结时复用前文编号和短名回顾；有建议时逐条出现；最后落在真实结论上。原片没有总结、建议或行动号召，不擅自编造。

贴纸分层设计：主标题、章节编号和重点数字用圆润粗字、蓝色清晰描线、虹彩字面、银彩细闪底纸；普通关键词和列表用圆润蓝字、浅色珠光底纸和柔和阴影；轻注释使用真实的手写感字体。中文使用实际可用且适合使用的字体，不能整片只用同一款方黑体。为适合的疑问、情绪或类别主动加入少量 emoji，例如 🤔、🧩、🎬、💡、😍，emoji 与文字连成同一张贴纸；编号列表不必每行额外塞表情。优先保留文字可编辑性。

停留阶段也要有轻微动态：文字、emoji、底纸与阴影整体缓慢前后轻倾、轻摆，列表每行有不同相位，保持行距和阅读位置。主标题的虹彩和柔和反光持续缓慢变化，像转动闪卡时换了颜色；细闪固定在材质表面，只随光改变亮度。不能只做一张静态彩色 PNG 后停住，也不能高频乱抖、逐字乱跳或每帧重新撒噪点。角标和长句应比重点字更安静，清晰度始终优先。

时间与节奏：先确定保留的口播，再以触发词的真实时间安排每张贴纸。新信息分别入场，不平均分配时间，不提前泄露后面的观点。入场轻快、稳定阅读时间足够，旧内容按语义结束退场。列表项与章节标签可保留，普通关键词不累积成墙。人物布局变化发生在列表、案例或段落转换处，不来回乱滑。保留自然呼吸，不默认增加音乐、密集音效、配音或虚拟人。

先做一份简短剪辑表：成片起止时间、对应原片时间、触发原话、人物位置、贴纸内容和出场顺序、素材片段、退出或保留规则。然后实际制作可播放的视频，检查抠像运动边缘、文字遮挡、出字时机、编号一致性、素材对应、音画同步、开头结尾和阅读节奏。用连续画面核对闪卡变色、反光、emoji 和轻摆，不能用静帧或脚本生成成功代替动态效果完成。

先选原片中约 20–45 秒的连续完整语义段试剪，尽量包含留白和至少两种原片真实需要的画面模式，不为凑效果补造内容。交付可播放预览、真实可编辑工程或源文件、简短剪辑表和未解决项，确认试剪风格后再扩展到全片。

优先使用我指定或当前已可用的编辑工具；不覆盖原片，不擅自启用付费 API、上传私人素材或生成替身。若当前工具不能完成人物抠像、描边或渲染，先完成可做的剪辑分析，并明确具体缺口；不要用矩形白框、模糊背景或静态方案冒充完成。
```
