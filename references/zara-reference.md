# Zara 参考片拆解

灵感来源：**[Zara Zhang 在 X 分享的口播视频](https://x.com/zarazhangrui/status/2116281211962454056)**。

作者主页：[X](https://x.com/zarazhangrui) · [GitHub](https://github.com/zarazhangrui)。

以下从人物构图、文字呈现和信息层级三个方面整理这条视频的视觉手法。

## 可复用的视觉语言

| 原片中观察到的方式 | 对新视频的启发 |
| --- | --- |
| 白描边人物，浅色网格背景，头顶与左右留白 | 人物是稳定的视觉锚点，信息在周围出现 |
| 左侧划掉 designer，右侧 tasteful 更大且彩色 | 用空间、符号和大小表达明确的否定转折 |
| 关键词之后清屏，只保留人物 | 铺垫和过渡不必硬加文字 |
| 头顶主题、右侧说明、左侧否定图形依次加入 | 文字按讲述顺序出现，位置不决定先后 |
| 人物移左，右侧先总标题、再逐项增加列表 | 让观众跟随口播逐步获得信息 |
| 左侧大编号，右侧章节短名 | 用短暂的强层级画面引入新要点 |
| 展开后左上角保留编号与短名 | 降低层级但保留位置感，不让导航持续抢眼 |
| 讲案例时，人物在左、素材区域在右 | 素材配合解释，关键细节需要可读 |
| 保留同一人物与素材布局，改变背景颜色 | 强调可以只改变一个层次，避免所有元素一起运动 |
| 回顾时复用此前的编号与短名 | 视觉呼应有助于辨认和记忆 |
| 结尾以 input/output、等号与加号表达关系 | 左右不只表示对错，也可以表达过程与并列关系 |

## 几个容易误学的地方

### 左否右肯只用于明确的否定转折

原片开头适合这种布局，但后面也有右侧同时放 good 与 slop 的局部排法。结尾的两个身份则是并列相加。新片应先判断语义，再决定空间关系。

### 四个观点是这条视频的内容

列表数量和章节数量来自口播。三个原因就用三项，六个步骤就按可读性分组；只有一段经历和一个结论时，也可以只使用留白、关键词、案例和结论画面。

### 小标签从第一点就开始使用

第 01 点展开后已经出现左上角标签，后续章节延续同一规则。标签与临时关键词的生命周期不同：关键词可以退出，标签保留到该章节结束。

### 总览、章节内列表和行动建议属于不同层级

章节内部可以有局部问题清单，结尾的建议数量也可以与开头观点数不同。不要把所有列表都强制合并成一套编号。

### 只迁移方法，不搬运内容

新片使用自己的主题、人物、数字、结论和素材。原视频中的英文词、10× 等表述不是可套用到所有视频的主张。

## 应用于新视频

按新片的口播确定文字和素材的出场时机，再根据人物比例与可读性调整构图。尺寸、配色和时间范围可参照 [视觉与动效规范](visual-grammar.md)；动态字样见 [动态贴纸与闪卡材质](sticker-materials.md)。
