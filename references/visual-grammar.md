# 视觉与动效规范

以下参数以 1920×1080 为基准，可根据实际人物比例、手势、字幕、语言长度和素材可读性调整。

## 构图与层级

以画面左上角为 (0,0)，宽高分别为 W/H；下文百分比均相对最终画面。不要混用剪辑器以中心为原点的坐标。

| 场景 | 推荐起点 | 优先检查 |
| --- | --- | --- |
| 居中讲解 | 人物中心 x≈50%W，轮廓宽约 48–56%W，底部自然出画，头顶 y≈18–23%H | 不裁头、不拉伸；头顶容得下标题，两侧容得下短贴纸 |
| 左侧讲解＋列表/素材 | 人物中心 x≈28–30%W，轮廓宽约 42–48%W；最左可见轮廓距边约 4–7%W | 身体和白边不要贴边；右侧信息区从 x≈57%W 开始，到 94%W 结束 |
| 头顶主标题 | 在 x≈15–85%W、y≈6–18%H 的区域中排版 | 可从人物后方升起，停稳后关键文字完整；标题变长先压缩表述或换行 |
| 章节角标 | x≈4%W、y≈5%H；整体高约 5–7%H，宽按短名 | 编号、短名在全片同位置同规格；不要挤成横跨顶部的主标题 |
| 普通信息安全区 | 左右至少约 5%W，上下至少约 6%H | 人物底部是自然出画的例外；有连续字幕时额外预留底部约 12–16%H |

用**实际抠像轮廓**判定人物占位，不用原视频矩形边界估算。人物与素材/贴纸通常留 2–4%W 的视觉间隙；遇到动作侵入时移动文字或调整整体构图，不把人压成细条。先减字、重排或分屏，最后才小幅缩字。

基本层序从后到前：背景 → 网格/纹理 → 后景标题或连线 → 素材卡片 → 人物白描边 → 人物 → 前景关键词/章节标签 → 连续字幕。按场景调整，但脸部保持保护区；放在人物后方的连线不能影响关系辨认。

主标题可以在入场途中短暂被头部遮挡，最终停稳必须可读。正文关键词默认避开脸、眼、嘴和发顶；不为了复刻“头后大字”把关键词长期藏掉。

## 人物抠像和白边

- 1080p 起点：白色外描边约 16–26 px，按画面等比例缩放；可加很弱的柔阴影，但不能变成厚黑晕圈。
- 白边由人物 alpha 轮廓向外扩张得到，人物本体叠回最上方；不能对白色矩形素材框描边冒充抠像。
- 在明、暗背景上查看发丝、肩膀、衣服与手部；检查连续帧的轮廓是否跳动。修边与时间稳定性比一帧精细发丝更重要。
- 不默认磨皮、美颜或改变身份特征。原片缺了头顶或手部时，不承诺通过缩放把未拍到的部分恢复。

## 背景、字体与贴纸

推荐色板可直接用于初版，品牌要求优先：

| 用途 | 起始颜色/质感 |
| --- | --- |
| 常态底色 | 暖米白 `#F2EFE6`，低对比细网格 |
| 章节变化 | 淡紫 `#E8E6F4`、淡粉 `#F6ECE7`，明度接近 |
| 重点背景 | 蓝色 `#3D49DA`；只在重要关系或结论处使用 |
| 主文字 | 蓝色 `#3D49DA`，白色贴纸轮廓 |
| 否定标记 | 珊瑚红 `#F66D63`；配斜线、叉号或明确否定词 |
| 主标题/大编号 | 虹彩闪卡：圆润粗字、清晰蓝色描线、银彩底纸和细闪；颜色与反光随轻摆缓慢变化 |

网格线在 1080p 可从 48–64 px 间距、1 px 线宽、约 3–6% 不透明度试起。背景纹理安静；贴纸的固定细闪可以随光线缓慢改变亮度，不做每帧重置的随机噪点。深蓝背景上换合适的高对比字色或浅色贴纸底，不让蓝字直接消失在蓝底上。

文字分三个角色：

- **主标题/章节编号/关键数字**：最醒目的圆润字形；虹彩字面、蓝色描线、银彩细闪底纸，整屏通常一个主焦点。
- **普通关键词/列表项**：圆润蓝字、浅色珠光模切底纸、柔和阴影；可带一个语义 emoji。编号和词组连成一张贴纸，不默认使用生硬方黑体。
- **轻注释**：真实手写感字体、更轻的笔画和略有变化的字势；与重点字形成反差，不能只把主字体机械倾斜。

中文用实际可用且可使用的中文字体；粗体适配标题，手写字体只在真实存在且字形齐全时用于注释。不要为了像英文参考强套英文斜体、逐字散排或不存在的中文字体。

1080p 试排起点：主标题 88–128 px，关键词 58–84 px，列表 48–64 px，角标 32–44 px。工具的字号单位可能不同，以实际画面校准。普通贴纸底纸可从字形向外延伸约 12–18 px，主闪卡约 20–30 px，阴影不透明度约 12–20%。底纸要连成一张，边缘圆润。数值不代替小屏阅读检查。

优先短句：中文关键词多为 2–8 字，列表短名约 4–12 字；这不是字数硬门槛。超长项应提炼准确短名或在语义允许时分两行，不删掉关键限制词。保留原话需要长句时，给它专门的宽卡片和阅读时间。

主动为适合的疑问、态度或类别选择 emoji，例如 🤔 疑问、🧩 拆解、🎬 视频、💡 想法、😍 喜爱。每组通常一个，一屏通常 1–2 个主 emoji 组，纯编号列表不必额外逐行加表情。没有合适图标时用简洁符号或留白。emoji 与文字共用底纸、描边和阴影，不能以没做彩色字体支持为由直接漏掉。具体选择、材质与动效见 [动态贴纸规范](sticker-materials.md)。

## 各种画面怎么动

下面的时间是调节范围；锚点来自新片原声，不从原参考照搬时间码。

| 动作 | 推荐起点 | 语义约束 |
| --- | --- | --- |
| 普通贴纸入场 | 0.15–0.30 秒淡入＋96%→100% 缩放，或小幅上移 | 在对应词开始处启动；不提前让观众读到后面的观点 |
| 强调贴纸 | 0.18–0.35 秒，最多轻微过冲一次 | 用于真正的主数字/结论，普通词不全用弹簧 |
| 停留时整贴轻摆 | 约 ±0.6–1.3° 轻旋转、±1–3 px 浮动；轻微前后倾斜 | 慢速、连续、整贴一起动，不能让文字只在入场时动一下 |
| 列表逐行轻摆 | 每行约 ±0.4–0.8°，使用不同起始相位 | 编号和文字同组；保持顺序、行距与稳定的阅读位置 |
| 虹彩与反光 | 柔和的颜色位移和宽反光带缓慢变化 | 细闪固定在底纸/字面，不向画面外飞，不遮住字边 |
| 贴纸退出 | 0.12–0.20 秒淡出或干净切走 | 句意结束或转入下一组信息；避免叠成墙 |
| 人物中间→左侧 | 在语义边界直接切换，或 0.25–0.45 秒平滑移动 | 为列表/素材腾位置；不每句话左右滑动 |
| 章节引入 | 大编号先到，标题按实际说到的顺序加入 | 对应引入通常约 1–2.5 秒；不为撑满时长冻结口播 |
| 大章节→小标签 | 0.25–0.45 秒收束，或切成同语义的小角标 | 标签留到该点讲完；不能因关键词清屏一起误删 |
| 背景变化 | 在概念边界切色，或 0.20–0.45 秒过渡 | 不随每句话闪色，保留同一套字体和贴纸体系 |

对齐时，把**首个可见帧**放在触发词/自然引入的起点；普通入场应很快可辨。在词很短或口播很快时用直接出现、减少效果，不能等词讲完后才开始慢慢打字。

短关键词通常留出至少约 1–1.5 秒稳定阅读时间；列表项可从出现一直保留到该列表结束；长句与小屏观看需要更长。上述范围不是强制延长原声的理由：来不及读时删减冗余文字、减少事件或选更短关键词。

一组列表的流程：标题 → 第一个已讲到的点 → 保留第一点并加入第二点 → 继续到真实最后一点。列表项超过单屏可读范围时按真实分组分页，或只保留当前项与必要上下文；不能为了仿四点模板删掉第五点。

结束一组信息后可清屏回到人物，制造呼吸。空白不是遗漏；过渡句、情绪表达和没有新概念的解释可以只保留人像与章节角标。

## 素材卡片与声音

人物＋素材画面优先用一张主素材卡；确实需要比较时才并置两张并给短标签。圆角、白边、柔阴影与轻微倾斜可用于形成贴纸感，但文字密集的 UI、表格或文档尽量摆正并放大关键区域。

先读得清，再保留“人物永远在左”的形式。细节实在太小时，短暂切全屏素材或局部特写，原声继续，随后回人物；这是可读性的可用变体，默认仍优先人物配素材。

素材在口播说到对象时出现，讲运动就播放对应的运动；素材原声默认静音，除非需要其声音作为证据。需要文字强调时在素材附近加一个短注释，不同时堆主标题、双图、长列表与多个数字。

默认保留原声，不新增配音。音乐和贴纸音效不是该风格的必备条件；用户要求时使用有来源的适量声音并避开语音重点。不能根据静态截图推断参考片的音乐、音量或音效。
